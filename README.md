# ระบบจัดการร้านค้า

เดโมหน้าเว็บสำหรับบันทึกสินค้า ราคา ต้นทุน และจำนวนคงเหลือ พร้อมสรุปจำนวนสินค้า มูลค่าสต็อก และรายการสินค้าใกล้หมด

## เริ่มใช้งาน

เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งแพ็กเกจหรือเริ่มเซิร์ฟเวอร์

## ความสามารถ

- เพิ่ม แก้ไข และลบสินค้า
- แสดงกำไรต่อชิ้นและสถานะสต็อก
- สรุปจำนวนสินค้า จำนวนคงเหลือ มูลค่าสต็อก และสินค้าใกล้หมด

ข้อมูลถูกเก็บใน `localStorage` ของเบราว์เซอร์ที่ใช้งาน ไม่มีฐานข้อมูลหรือระบบบัญชีผู้ใช้ ข้อมูลจึงไม่ซิงก์ข้ามอุปกรณ์ และอาจหายเมื่อผู้ใช้ล้างข้อมูลเว็บไซต์

โปรเจกต์นี้จัดทำเพื่อการศึกษา
